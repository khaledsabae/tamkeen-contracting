# TAMKEEN Contracting — Cinematic Demo

Premium scroll-driven demo website for TAMKEEN Contracting.

## Run
```bash
npm install
npm run dev
```

## Required media
Create `public/media/` and add:
- `cinematic-master.mp4` — final combined transition film
- `cinematic-poster.webp` — poster/fallback image

The cinematic story maps scroll progress to video time. Text, CTAs and navigation remain semantic HTML overlays and are not baked into the video.
